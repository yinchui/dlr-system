# DLR 安全系数与静态基准移除设计

## 1. 目标

系统不再展示或计算用于页面对比的静态额定基准值。所有后台最终发布的动态线路额定值统一乘以 `0.8` 安全系数，页面、下载、瓶颈统计、审计和弧垂后验证快照只消费折减后的结果。

IEEE 738 稳态和暂态热计算内核保持标准原值，不在物理公式内部引入安全系数。因此 Drake 等标准回归值继续用于验证热核正确性，安全系数只属于额定值发布策略。

## 2. 唯一折减边界

新增后台常量：

```python
DLR_SAFETY_FACTOR = 0.8
```

`DlrPipeline` 在热核计算完成、结果进入 `DlrPipelineResult` 之前执行一次折减：

```text
IEEE 738 原始稳态结果 ─┐
                       ├─> 发布边界 × 0.8 ─> DlrPipelineResult
IEEE 738 原始暂态结果 ─┘                         ├─> 页面与下载
                                                ├─> 瓶颈统计
                                                └─> 弧垂后验证快照
```

具体规则：

- 稳态 `max_currents` 乘以 `0.8`，并同步写回 `thermal_result["max_currents"]`；
- 成功暂态的 `transient_result["max_currents"]` 乘以 `0.8`；
- 暂态失败时直接复用已经折减的稳态数组，禁止再次乘以 `0.8`；
- 额定值必须保持有限、非负、形状不变，正比例折减不改变瓶颈塔索引；
- 后台结果记录 `safety_factor=0.8`，页面不新增系数控件或说明标签；
- `input_hash` 继续表示规范化热核输入，安全系数作为发布策略元数据单独记录，避免改变既有哈希语义。

## 3. 静态基准移除

线路全景页面删除：

- 静态工况参数构造和静态额定值计算；
- “对比静态”增幅百分比；
- “静态额定值（基准）”指标；
- 静态额定值虚线；
- 基于静态线填充的“增容空间”区域。

统计摘要保留最低、最高和平均动态额定值。单塔详情、热力图、气象修正和 AI 指标布局不重构。

未被运行页面调用的 `build_line_rating_figure` 同步收敛为只接收动态额定值，防止静态基准能力通过旧辅助接口继续存在。相关旧测试和文档描述同步更新。

## 4. 数据一致性

发布后的以下数据必须完全一致：

- `DlrPipelineResult.max_currents`；
- `DlrPipelineResult.thermal_result["max_currents"]`；
- `to_legacy_line_data()["max_currents"]`；
- 成功暂态 `thermal_result["transient_result"]["max_currents"]`；
- 暂态失败回退矩阵；
- `st.session_state.line_data["max_currents"]`；
- 弧垂后验证快照中的原始额定电流矩阵。

不保留可被页面误用的未折减额定值副本。IEEE 738 原始值仅作为流水线函数内部的临时计算结果。

## 5. 错误处理

- 安全系数由配置固定为有限且处于 `(0, 1]` 的浮点数；配置测试防止非法值进入运行时；
- 折减前后均维持现有的有限、非负和形状校验；
- 暂态结果无效时沿用现有稳态回退路径，再由唯一发布边界保证只折减一次；
- 安全系数不影响气象训练、MAE/RMSE、模型晋级或 IEEE 738 热平衡。

## 6. 测试与验收

按 TDD 增加以下回归：

1. 配置明确为 `0.8` 且合法；
2. 稳态流水线结果等于热适配器原始结果的 `0.8`；
3. 成功暂态结果等于原始暂态结果的 `0.8`；
4. 暂态失败回退等于已折减稳态结果，不发生 `0.64` 二次折减；
5. legacy 投影和弧垂快照只获得折减值；
6. 页面源代码不包含静态基准计算、指标、图线或“对比静态”文本；
7. 可视化辅助接口不再接受静态额定值；
8. IEEE 738 标准回归保持原始参考值；
9. 全量自动化、Ruff、编译和浏览器桌面/移动验收通过。
